# Assignment: Tensors and Data

In this assignment you will learn the basics of Python and PyTorch tensors. Tensors are data structures used to index and manipulate numerical data. You will be working with different data formats (numerical, text, and image) and seeing how they are represented with tensors.

## Learning goals

By the end you will be able to:

1. Understand the basics of writing Python.
2. Be able to create and manipulate PyTorch tensor objects.
3. Know how to represent and compute with common data formats as tensors.

## Setup

Follow **Getting Started** in the [root README](../../README.md) to clone the repository and create and activate a virtual
environment.

Run every command below **from the repository root** to avoid import errors. With your virtual environment activated:

```
python -m assignments.tensors_and_data.tensors_and_data          # run showcase
```

If you use uv, you can skip activation and prefix each command with `uv run` instead:

```
uv run python -m assignments.tensors_and_data.tensors_and_data
```

## What is provided

To start, the general structure of the tensor showcase file has been provided. `tensors_and_data.py` sets up the basic structure of the data types and printouts.

Your goal is to implement all the sections labeled *TODO*.
